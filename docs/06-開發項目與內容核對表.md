# 長照交通接送後台系統 — 開發項目與內容核對表

> 版本：v1.0  
> 日期：2026-08-25  
> 用途：本文件彙整長照交通接送後台系統之所有開發項目與功能內容，供客戶逐項核對與需求確認。

---

## 系統開發項目清單

| 編號 | 開發項目 | 功能與內容說明 |
| :---: | :--- | :--- |
| **01** | **基本資料主檔管理** | • **個案資料建檔**：姓名、身分證字號、住家地址、補助類別、長照等級等完整個案資料。<br>• **車輛與司機主檔**：15 台車輛車號、15 位司機基本資料與預設車輛配置。<br>• **服務據點管理**：各接送機構／日照中心之名稱與地址。<br>• **固定排班設定**：設定每位個案固定搭乘的星期、車次、上下車時間、單價、里程（支援「單向 1 趟」、「一般去回 2 趟」、「多時段 4 趟」）。<br>👉 *所有基本資料只需在系統建檔一次，後續產表自動帶入，無需每月重複輸入。* |
| **02** | **每日回報自動匯入** | • 自動同步 15 位司機每日填寫的 Google 表單搭乘紀錄（包含去回程有坐／沒坐、問題回報）。<br>• 管理者無需逐一登入 15 份表單查看，由系統自動集中彙整。 |
| **03** | **政府申報表一鍵匯出** | • 選擇年月後，**一鍵產生符合政府規範的 33 欄制式申報 Excel 檔案**。<br>• 自動依個案規則處理申報細節：<br>&emsp;- 去程與回程的「出發地／目的地」地址自動對調。<br>&emsp;- 搭乘日期自動換算為政府規範之民國碼（如 1150701）。<br>&emsp;- 自動帶入司機身分證、車號、個案單價、里程與服務起訖時間。<br>&emsp;- 一天 4 趟個案自動展開四個時段紀錄、單向搭乘正確產出單趟。<br>• 支援批次打包下載全部個案申報檔，供直接上傳政府線上申報系統。 |
| **04** | **資料防呆與異常核對** | • **缺漏提醒**：若個案缺少身分證、地址或里程等必填欄位，匯出時主動提示，避免報送失敗。<br>• **異常確認清單**：同日搭乘不同車輛、或表單出現特殊備註時，列出清單供管理者快速人工確認。<br>• **回報內容更正**：司機在表單填錯、漏填或事後補報時，管理者可於後台逐筆修改該筆紀錄（搭乘狀態、車輛、司機、時間）。<br>• **異動軌跡追蹤**：所有手動調整皆完整記錄修改人、時間與修改前後的內容，並保留司機的原始回報，供日後查帳稽核（修改原因為選填，附常用原因快選）。 |
| **05** | **司機未回報通知** | • 每日定時自動檢查當日尚未送出回報表單的車輛。<br>• 自動發送 Email 提醒管理者，避免漏填問題延誤至月底。 |
| **06** | **新竹接送時刻表** | • 依照現有格式產生新竹區搭車順序時刻表（含去回程循環趟序、個案姓名、預計出發與抵達時間、地點）。<br>• 每月可直接匯出並列印提供給新竹縣政府備查。 |
| **07** | **車輛趟數彙總表** | • 依車輛與月份彙整搭乘人次與出車趟數，供內部營運統計與檢視。 |
| **08** | **車輛維修保養管理** | • 系統產出車輛定期保養檢查空白表單，供司機人工填寫。<br>• 提供線上登錄保養項目與歷史維修紀錄查詢。 |
| **09** | **出勤與油資登錄** | • 提供司機每日出勤狀態（正常出勤、請假、代班）線上登記。<br>• 提供車輛加油費用與發票資訊登錄，建立完整歷史紀錄。 |
| **10** | **營運狀況儀表板** | • 以直觀圖表呈現車隊出勤狀況、各車接送趟數趨勢、個案補助額度使用情形等。 |
| **11** | **司機請假即時通知** | • 司機請假時，即時發送 Email 通報業主與主管，並自動於每日未回報排程中排除誤報。 |
| **12** | **司機薪資計算表** | • 依據司機底薪、跑班趟次獎金、請假扣款、油資結算等規則自動計算月薪。<br>*(需由貴機構提供計薪規則公式)* |
| **13** | **營運成本與核銷管理** | • 每趟接送的成本拆解、利潤分析與內部核銷明細報表。<br>*(需由貴機構提供成本計算與核銷流程規則)* |

---

## 備註說明

1. **現行習慣保留**：系統完全相容目前 15 位司機填寫 Google 表單的習慣，司機端無須更換操作方式。
2. **待提供規則項目**：項目 12（薪資計算）、項目 13（成本與核銷）需待貴機構提供具體計算公式與流程後啟動對應邏輯開發。
